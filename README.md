# Synora Code

Synora Code is a private TUI-first coding harness forked from opencode.

The Phase 1 target is a clean backend runtime for approved Synora infrastructure:

- Azure AI Foundry deployments in `nps-foundry`;
- AWS Bedrock Claude 4.6 inference profiles;
- native protocol routing;
- deterministic cache and context handling;
- long-session stability.

This repository is not a public provider catalogue and does not aim to preserve upstream opencode product surfaces.
